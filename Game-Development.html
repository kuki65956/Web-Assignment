Game Development

Design and develop interactive and immersive games.

Course Overview

This course teaches you the core principles of game development, from conceptualization to creating playable games. You’ll learn how to design game mechanics, create 2D and 3D assets, and code your own interactive games using popular game engines.

What You Will Learn

  • Game Design Principles and Mechanics
  • Introduction to Game Engines (Unity, Unreal Engine)
  • 2D and 3D Game Development Techniques
  • Game Physics, AI, and Pathfinding
  • Building Interactive User Interfaces (UI)
  • Game Optimization and Debugging
  • Publishing and Marketing Your Game

Instructor

David Miller - Senior Game Developer with over 8 years of experience in creating indie games, mobile games, and virtual reality experiences.
